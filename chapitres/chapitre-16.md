## Chapitre 16 --- Petit glossaire

  -----------------------------------------------------------------------
  Terme                               Définition
  ----------------------------------- -----------------------------------
  Token                               Unité de texte manipulée par le
                                      modèle

  Vocabulaire                         Ensemble des tokens possibles

  Tokenizer                           Programme qui convertit texte et
                                      tokens

  Embedding                           Vecteur appris associé à un token
                                      ou une position

  Logit                               Score non normalisé produit pour
                                      une classe ou un token

  Softmax                             Transformation de scores en
                                      probabilités

  Attention                           Combinaison pondérée d'informations
                                      entre positions

  Query                               Vecteur qui formule une recherche

  Key                                 Vecteur comparé aux queries

  Value                               Vecteur dont le contenu est combiné

  Attention causale                   Attention qui interdit de regarder
                                      les positions futures

  Transformer                         Architecture utilisant notamment
                                      l'attention

  Loss                                Mesure numérique de l'erreur
                                      d'apprentissage

  Gradient                            Dérivée de la loss par rapport à un
                                      paramètre

  Optimiseur                          Algorithme qui met à jour les
                                      paramètres

  Epoch                               Passage complet sur les données
                                      d'entraînement

  Batch                               Lot d'exemples utilisé pour une
                                      mise à jour

  Overfitting                         Surapprentissage des données
                                      d'entraînement

  Inférence                           Utilisation du modèle entraîné pour
                                      produire une sortie
  -----------------------------------------------------------------------
